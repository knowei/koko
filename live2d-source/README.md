# 可可 Live2D 原画准备包

## 当前可用内容

- `original-expressions/`：四张透明完整立绘，可用于造型、配色和表情参考，也继续作为网页回退图。
- `reference/koko-head-parts-reference.png`：脸、眼睛、嘴形、刘海、侧发与发带补画参考。
- `reference/koko-body-parts-reference.png`：后发、躯干、手臂、服装、裙片和鞋袜补画参考。
- `layer-manifest.json`：PSD 分组、图层名称、绘制要求和 Cubism 参数映射。

## 重要限制

两张 `reference` 图片的棋盘格是画进 RGB 图片的，不是真透明背景，只能作为重绘参考，**不要直接导入 Cubism**。正式导入前需要在绘画软件中把部件逐个重绘或抠出到透明图层，并补足被遮挡区域。

## 你在 Cubism 前需要完成

1. 新建 2048 × 3072、透明背景、sRGB 的 PSD。
2. 依据 `layer-manifest.json` 建立同名图层组。
3. 以 `koko-base.png` 为对位基准，把参考板中的部件重新放回完整人物坐标，而不是保留零件表布局。
4. 每个关节和发束在遮挡方向保留至少 40～80 px 出血；眼球必须完整绘制在眼眶下方。
5. 检查隐藏区域：刘海下额头、后发后的颈肩、袖子下手臂、上衣下腰部、裙子后的双腿。
6. 删除所有白底、棋盘格和测试标记，PSD 中只保留角色透明图层。

完成 PSD 后再导入 Cubism。第一次导入只绑定头部转动、眨眼、视线、嘴形和呼吸，确认图层接缝正常后再做头发及裙摆物理。
